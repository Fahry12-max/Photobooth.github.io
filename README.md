# 📸 Photobooth✨

Photobooth web app dengan tampilan aesthetic dan fitur capture foto langsung dari browser.  
Simple, cute, dan bisa dipakai kapan aja tanpa install aplikasi tambahan 💖

## ✨ Features

- 📷 Capture foto langsung dari kamera
- ⏳ Countdown sebelum foto diambil
- 🎨 Multiple filter effects
  - Normal
  - Vivid
  - Soft
  - Warm
  - Cool
  - Mono
- 🖼️ Pilihan frame aesthetic
- 🎞️ Generate photostrip otomatis
- 💾 Download hasil photostrip
- 📱 Responsive mobile design

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

---

## 🚀 How To Use

1. Buka website
2. Klik **Start Session**
3. Izinkan akses kamera
4. Klik **Capture**
5. Ambil 4 foto
6. Klik **Generate Strip**
7. Download hasil photostrip ✨
